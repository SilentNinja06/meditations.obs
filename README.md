# Meridian Discipline — BRAT distribution

Built artifacts for the **Meridian Discipline** Obsidian plugin (a phase-aware
meditation & discipline practice: guided session runner, digital candle anchor,
post-session logging, lightweight stats, and Phase-3 bookends).

Source lives in the `obsidian_workspace.obs` monorepo (`plugins/meditations`);
this repo carries only the built `main.js` / `manifest.json` / `styles.css` /
`versions.json` for install via [BRAT](https://github.com/TfTHacker/obsidian42-brat).

Add `SilentNinja06/meditations.obs` in BRAT to install and auto-update.
